# LifeLink CRM 🩸

A Salesforce-based Blood Donation Management System developed using Apex, Lightning Web Components (LWC), and Experience Cloud.

## 📌 Project Overview

LifeLink CRM is a centralized platform that connects blood donors, hospitals, and emergency blood request services.

## 🚀 Features

### Donor Management
- Donor Registration
- Blood Group Tracking
- Availability Status
- City-Based Search

### Hospital Management
- Hospital Directory
- Contact Information
- Location Details

### Blood Request Management
- Emergency Blood Request Form
- Blood Group Selection
- Required Units Tracking
- Emergency Priority Levels
- Automatic Request ID Generation
- Salesforce Record Creation

### Experience Cloud Portal
- Public Access Website
- Responsive User Interface
- Multi-page Navigation

## 🛠 Technologies Used

- Salesforce CRM
- Apex
- Lightning Web Components (LWC)
- Experience Cloud
- SOQL
- Git & GitHub

## 📂 Custom Objects

- Donor
- Hospital
- Blood Request

## 🎯 Project Outcome

- Developed a Salesforce CRM Prototype
- Connected Frontend and Backend using Apex
- Implemented Blood Request Record Creation
- Built a Public Experience Cloud Portal
